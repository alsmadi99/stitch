Why Stitch?

Because that is literally the job. Every crossfade is a stitch, the reel is the quilt, and ffmpeg is the sewing machine doing the needlework at three in the morning while you sleep.

We considered calling it Quilt. Nobody wants to tell their friends about a Discord bot called Quilt.

It fits the temperament too. Stitch takes a pile of chaotic, badly-behaved little monsters that have nothing in common — different resolutions, different frame rates, one of them has no audio at all, one of them is somehow 4:3 — and patiently makes them into a family. Nothing gets left in the queue.

How it works

#gaming-clips→ ingest→ dedupe→ queue→ normalize→ stitch→ YouTube
🧵

Sews, doesn't staple

Every clip is normalized to one resolution, frame rate and loudness first, so twenty mismatched sources cut together without a jolt.

👀

Spots repeats

Three layers of duplicate detection, including a perceptual fingerprint that recognises the same clip re-uploaded through a different capture tool.

🔒

Private until you say so

Uploads land private by default. Publishing is a decision someone makes, never a side effect of a config file.

🪶

Fits on a small box

Peak memory is a tuning knob, not a surprise. Clips fold in batches so a twenty-clip reel never needs four gigabytes.

❌

Veto with a reaction

React on a clip and it leaves the queue. Remove the reaction and it comes back. You choose who the bot listens to.

🔁

Survives the night

Quota exhausted, container restarted, terminal closed — it picks up where it stopped and finishes without being asked.

Measured, not guessed

The fiddly parts of a video pipeline fail invisibly. These numbers come from the test suite, not from watching the output and nodding.

−323 → −44 msaudio drift across a reel, and no longer accumulating
0.8 vs 22–38fingerprint distance: same clip re-encoded vs unrelated footage

Get started

Clone it, fill in four values, and let doctor tell you what is missing. You do not need YouTube credentials to try it — leave them blank and reels are compiled locally so you can watch one before pointing it at a real channel.

# clone and install
git clone https://github.com/your-user/stitch.git
cd stitch && npm install && cp .env.example .env

# check every integration point — changes nothing
npm run doctor

# run it
npm run dev
